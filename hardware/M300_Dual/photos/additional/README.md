# Additional photographs — M300 Dual

This directory accepts the 27 additional board photographs provided in two batches:

- Batch 1: `IMG_8997 2.jpg`, `IMG_8998.jpg`, `IMG_8999.jpg`, `IMG_9001.jpg` through `IMG_9011.jpg`.
- Batch 2: `IMG_9012.jpg` through `IMG_9024.jpg`.

**Nothing has been uploaded to this directory yet.** The GitHub Actions workflow `.github/workflows/m300-dual-photos.yml` validates the expected 27 originals, converts each photo to PNG without EXIF metadata, combines them with the existing 21-photo PNG archive, checks for 48 distinct images, and commits `M300_Dual_Photos_48_PNG.zip`.

Upload the actual image files, not screenshots of this README. The workflow stops without publishing a supposedly complete ZIP if any expected photo is missing.
