# Pochodzenie

Repozytorium zachowuje oznaczenia GPL portu i przypiętego Klippera; zobacz LICENSE.
Księżyc i sprite pochodzą z dostarczonego firmware M300 stock 1.3.1. Własność
rysunków producenta pozostaje niezmieniona. Deskryptor księżyca, suma klatki
i obrazu źródłowego są w m300_display_oem.py; testy hosta weryfikują
m300_display_moon.json. Aplikacja stock i prywatne zrzuty fabryczne/seryjne
nie są publikowane.

R16 zmienia prezentację, adapter normalnego homingu, migrację zachowującą
kalibracje i grupowanie Fluidd. Źródła MCU R14.5 chłodzenia, lifecycle, guard
STEP i dekodera fabrycznego są zachowane. Źródło oficjalnego Marlina i dowody
selektora ID opisują FEATURES.md i HARDWARE_VARIANTS.md. Historyczne pliki
tests/reference nie są instalowane.
