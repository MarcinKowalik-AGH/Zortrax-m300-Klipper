# Połączenie Orange Pi z M300 Classic

Konfiguracja szeregowa hosta musi odpowiadać ustawieniu bootloadera. Po instalacji odczytaj `ZORTRAX_LINK_STATUS` i `ZORTRAX_MCU_STATUS`. W razie przerwania połączenia sprawdź zgłoszoną przyczynę oraz log Klippera przed restartem. [UART i pierwsze uruchomienie](FIRST_INSTALL.md) · [Parametry łącza](TECHNICAL_REFERENCE.md).
