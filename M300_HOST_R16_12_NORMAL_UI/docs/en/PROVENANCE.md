# Provenance

The repository follows the GPL notices of the port and pinned Klipper; see
LICENSE. Original moon/sprite artwork comes from the user-provided stock M300
1.3.1 image; vendor artwork ownership is unchanged. The moon descriptor, frame
hash and source-image hash are recorded in m300_display_oem.py and verified
against m300_display_moon.json by public host tests. The stock application and
private factory/serial dumps are not published.

R16 changes presentation, the normal homing adapter, calibration-preserving
configuration migration and Fluidd grouping. The R14.5 MCU cooling, lifecycle,
STEP guard and factory decoder sources remain unchanged. The official Marlin
reference and exact stock factory-ID selector evidence are documented in
FEATURES.md and HARDWARE_VARIANTS.md. Historic fixtures under tests/reference
are not installed.
